# 🎼 Lyra · Λύρα

**Lyra** — настольное приложение для изучения гамм, ладов и аккордов на грифе
и фортепиано. Пять инструментов синтезируются прямо в коде (без сэмплов),
интерфейс переведён на 16 языков.

## Установка и запуск

**Windows.** Скачайте `.exe` и запустите. Windows SmartScreen может показать
предупреждение (файл не подписан сертификатом) — «Подробнее» → «Выполнить в
любом случае».

**macOS.** Файл не подписан Apple, поэтому после скачивания снимите карантин:

```bash
chmod +x lyra-darwin-arm64      # или lyra-darwin-amd64
xattr -dr com.apple.quarantine lyra-darwin-arm64
./lyra-darwin-arm64
```

**Linux.** Нужны библиотеки OpenGL и X11 (обычно уже стоят):

```bash
chmod +x lyra-linux-amd64
./lyra-linux-amd64
# если не хватает зависимостей (Debian/Ubuntu):
sudo apt install libgl1 libx11-6 libxcursor1 libxrandr2 libxinerama1 libxi6
```

## Что умеет

**Lyra** — офлайн-приложение для изучения гамм, ладов, аккордов и переходов
между тональностями на интерактивном грифе и фортепиано. Ничего не грузит из
сети, звук синтезируется в реальном времени (без сэмплов).

**Гриф.** 4–9 струн, каталог строёв и свой строй по струнам, каподастр, число
ладов (6–24). Подсветка нот гаммы, клик по ладу — прослушивание ноты, тоники
и ноты гаммы отмечены отдельно. Аккорд накладывается поверх гаммы.

**Фортепиано.** Несколько октав с подсветкой гаммы и аккорда и аппликатурой
аккорда цифрами; прослушивание.

**Гаммы и лады.** Каталог из ~80 гамм: диатонические лады, мелодический,
гармонический и двойной гармонический минор/мажор и их лады, пентатоники
(включая японские и индонезийские), блюзовые, бибоп, симметричные лады
(уменьшённые, увеличенные, лады Мессиана), тхаты и раги. Есть **своя гамма** —
набор нот вручную. Выбор тоники, синонимы гамм, аккорд ступени, прослушивание.

**Аккорды.** Каталог типов аккордов (трезвучия, септаккорды, add/sus,
расширения). Для выбранной тоники и типа приложение находит **все играбельные
позиции** на текущем строе: до 4 прожатых ладов (открытые струны не
считаются), с учётом каподастра; список отсортирован от удобных к редким. Для
каждой позиции — **диаграмма-аппликатура**, полностью совпадающая с грифом, и
прослушивание.

**Переходы между гаммами (модуляция).** Две гаммы (исходная и целевая) и
**общие (pivot) аккорды** с их функцией и ступенью в обеих тональностях. Обе
гаммы подсвечиваются одновременно (общие ноты — ярче). Прослушивание первой и
второй гаммы и общего аккорда.

**Поиск «Гаммы по аккордам».** Задаёте аккорды символом (`Am`, `E7`) или
нотами (`C E G`) — приложение находит все гаммы, содержащие их, а по выбору
результата настраивает гриф и фортепиано.

**Звук.** Пять инструментов, синтез в коде: гитара, рояль, бас, флейта, арфа.
Настройка базового строя A4 (400–480 Гц). На Windows и macOS звук работает
(не только на Linux).

**Интерфейс.** Четыре визуальные темы (Мрамор, Сепия, Графит, Ночь), 16 языков,
адаптивная вёрстка (узкий/мобильный экран — инструменты сверху, панель снизу),
сброс настроек.
