# 🎼 Lyra · Λύρα

**Lyra** — настольное приложение для изучения гамм, ладов и аккордов на грифе
и фортепиано. Пять инструментов синтезируются прямо в коде (без сэмплов),
интерфейс переведён на 16 языков.

## Установка и запуск

**Windows.** Скачайте `.exe` и запустите. Windows SmartScreen может показать
предупреждение (файл не подписан сертификатом) — «Подробнее» → «Выполнить в
любом случае».

**macOS.** Файл не подписан Apple, поэтому после скачивания снимите карантин:

```bash
chmod +x lyra-darwin-arm64      # или lyra-darwin-amd64
xattr -dr com.apple.quarantine lyra-darwin-arm64
./lyra-darwin-arm64
```

**Linux.** Нужны библиотеки OpenGL и X11 (обычно уже стоят):

```bash
chmod +x lyra-linux-amd64
./lyra-linux-amd64
# если не хватает зависимостей (Debian/Ubuntu):
sudo apt install libgl1 libx11-6 libxcursor1 libxrandr2 libxinerama1 libxi6
```

## Что умеет

- **Гриф и фортепиано** с любой настройкой, числом струн (4–9) и каподастром.
- **Каталог из ~80 гамм и ладов** (диатонические, мелодический/гармонический
  минор и мажор, пентатоники, блюзовые, бибоп, симметричные лады и др.),
  а также **своя гамма** по нотам.
- **Аккорды**: подбор позиций на грифе, диаграмма, ступени гаммы, поиск
  подходящих гамм по набору аккордов.
- **Переходы между гаммами**: общие (pivot) аккорды, обе гаммы подсвечиваются
  одновременно.
- **Пять инструментов** — гитара, рояль, бас, флейта, арфа — синтез в реальном
  времени без сэмплов.
- **Шесть визуальных тем**, 16 языков интерфейса.

## Сборка из исходников

Бинарники собираются автоматически в CI (`.github/workflows/build.yml`):
Linux — в контейнере `ubuntu:20.04` (совместимость со старым glibc),
Windows — кросс-компиляцией MinGW, macOS (Intel и Apple Silicon) — нативно.
Пуш тега `v*` запускает сборку и публикует релиз.

Локально:

```bash
make check      # тесты
make dist-all   # linux + windows (+ macOS, если задан OSXCROSS)
```
